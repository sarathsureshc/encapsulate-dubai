# Encapsulate Coffee & Tea Capsules

> **Luxury Coffee & Tea Capsules Compatible with Nespresso® and Dolce Gusto® Machines in Dubai, UAE.**

Encapsulate is a high-end e-commerce web application for premium coffee and tea capsule enthusiasts. Built with a focus on modern aesthetics, speed, and conversion optimization, it showcases Italian-inspired blends, machines, gift bundles, and accessories delivered across the UAE.

---

## ☕ Key Features

- **Luxury Visual Design & Animations**: Smooth scrolling powered by Lenis, dynamic motion components, and refined micro-interactions.
- **Product Catalog & Categories**: Premium Coffee Capsules, Tea Capsules, Machines, Gift Sets, and Accessories.
- **Flavor Experience**: Interactive flavor notes detailing intensity, roast, sweetness, acidity, and aroma profiles.
- **Compatibility Checker**: Machine compatibility guides for Nespresso® and Dolce Gusto® coffee systems.
- **Subscription Club**: Monthly capsule subscription benefits with exclusive member pricing.
- **Optimized E-Commerce Flow**: Fast cart drawer, quick-add capabilities, promo code integration, and direct WhatsApp support.
- **Responsive & Accessible**: Optimized for mobile touch gestures, fast page loads, keyboard navigation, and structured SEO metadata.

---

## 🛠️ Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) & [TanStack Router](https://tanstack.com/router)
- **UI & Styling**: React 19, Tailwind CSS v4, Radix UI Primitives, Lucide Icons, Shadcn UI
- **Animations**: Motion / Framer Motion, Lenis Smooth Scroll, Embla Carousel
- **State & Data**: TanStack React Query, React Hook Form, Zod
- **Build Tooling**: Vite 8

## 🚀 Development Setup

### Prerequisites

- [Node.js](https://nodejs.org/) (v20+ recommended)
- `npm` or `bun`

### Installation & Run

1. Clone the repository:
   ```sh
   git clone https://github.com/sarathsureshc/encapsulate-luxury.git
   cd encapsulate-luxury
   ```

2. Install dependencies:
   ```sh
   npm install
   ```

3. Run the development server:
   ```sh
   npm run dev
   ```

4. Build for production:
   ```sh
   npm run build
   ```
